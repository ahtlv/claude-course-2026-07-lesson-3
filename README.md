# Занятие 3 — MCP: подключение внешнего мира → идея под тебя

Раздатка третьего занятия курса **«Claude Code: от нуля до уверенной работы»**
(BELHARD Academy, преподаватель — Анатолий Хотулёв).

---

## ⚠️ Сделать ДО занятия

**Прогони [промпт 09](prompts/09-playwright-mcp.md) дома, за пару дней до встречи.**

На занятии мы подключаем Claude Code к настоящему браузеру. Установка тянет из интернета
несколько сотен мегабайт, и если запускать это одновременно на всю группу, канал ляжет и
мы потеряем время на самом интересном месте. Дома это займёт минут десять, а на занятии мы
сразу перейдём к делу.

Ещё проверь, что папка с твоим персонажем на месте и файлы о тебе (`profile.md`,
`CLAUDE.md`, факты, проекты) никуда не делись с прошлого занятия. На занятии агент будет
искать идею проекта, опираясь именно на них: чем богаче описание, тем интереснее результат.

---

## Что сегодня

1. **Наведём порядок в конфиге.** Твои глобальные настройки Claude Code лежат в скрытой
   системной папке. Перенесём их в обычную видимую, чтобы дальше было удобно добавлять туда
   свои правила и скиллы.
2. **Разберёмся, что такое MCP** — способ подключить агента к внешним сервисам: браузеру,
   базам данных, твоим документам и заметкам.
3. **Поставим первый настоящий MCP — браузер.** Агент научится сам открывать сайты, ходить
   по ним и забирать оттуда информацию.
4. **Найдём идею под тебя.** Агент прочитает, кто ты, сходит на реальный список запросов
   рынка от главного стартап-акселератора мира и предложит проект, который растёт из тебя.

К концу занятия у тебя будет файл `идея.md`. На следующем занятии из него вырастет второй
артефакт курса — лендинг с работающей формой подписки.

и подбирает нужный способ. Отдельных инструкций под каждую ОС держать не нужно.
