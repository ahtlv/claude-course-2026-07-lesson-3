# Промпт 8 — Твой конфиг в собственном GitHub (бэкап + перенос между компьютерами)

**Когда:** сразу после промпта 7, в начале занятия 3, ещё до основной темы MCP — когда
`~/claude-config` уже существует и в него переехали `CLAUDE.md`, `settings.json`,
`rules`, `skills`, `commands`, `.mcp.json`.
**Что делает:** заводит **приватный** репозиторий на твоём GitHub и заливает туда
`~/claude-config` целиком. Дальше новое правило или новый skill можно так же залить
пуш-ем, а на другом компьютере — вернуть всё одной командой `git clone` + повторным
промптом 7.
**Как использовать:** отправь промпт ниже как есть.

> База, не факультатив: личный инструмент, которым пользуешься весь курс и после него,
> должен быть так же подстрахован, как обычный код (git+GitHub уже знаком с занятия 2) —
> иначе конфиг живёт только на одном компьютере и одна переустановка системы его сотрёт.

```text
Мой глобальный конфиг Claude Code теперь лежит в ~/claude-config (обычная папка, не
проект). Хочу завести под него отдельный приватный репозиторий на моём GitHub и залить
туда всё содержимое, чтобы можно было потом стянуть на другой компьютер.

Сделай так:
1. Перед тем как публиковать что-либо — открой файлы внутри ~/claude-config (особенно
   settings.json и .mcp.json, если он есть) и проверь на глаз, нет ли там паролей,
   токенов или ключей API прямо текстом. Если найдёшь — покажи мне и остановись, ничего
   не пушь, пока не решим, что с этим делать.
2. Если подозрительного нет — перейди в ~/claude-config и, если это ещё не
   git-репозиторий, инициализируй его (git init).
3. Создай на моём GitHub новый ПРИВАТНЫЙ репозиторий с названием claude-config
   (gh repo create) и подключи его как origin.
4. Добавь все файлы, сделай коммит и запушь.
5. В конце покажи мне ссылку на репозиторий и напомни, что дальше при любой правке
   конфига коммит и пуш нужно будет попросить отдельно — само по себе это не
   происходит.
```

**Дальше на занятии** — наставник коротко показывает перенос на новую машину:
`git clone <ссылка> ~/claude-config`, а дальше снова промпт 7 — он сам увидит, что файлы
уже лежат в `~/claude-config`, и просто досоздаст симлинки в системной папке.

> ⚠️ Приватный, не публичный — в конфиге может быть личное (как обращаться к тебе, твой
> стиль работы, возможно ключи в `.mcp.json`). Если случайно выбрал публичный —
> переключить обратно: `gh repo edit claude-config --visibility private`.
